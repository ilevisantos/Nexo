# Nexo

Controle financeiro pessoal desenvolvido como projeto de estudo.

O Nexo tem como objetivo centralizar o controle das finanças pessoais,
permitindo acompanhar receitas, despesas, contas, cartões e investimentos
de forma simples e organizada.

## Objetivo

O projeto está sendo desenvolvido para reforçar fundamentos de desenvolvimento
web enquanto explora, de forma progressiva, tecnologias utilizadas no mercado.

A ideia é começar com uma aplicação simples no frontend e evoluir posteriormente
para uma arquitetura com backend e banco de dados.

## Principais funcionalidades

- Registro de receitas e despesas
- Visualização do saldo
- Histórico de transações
- Categorias e classificações de transações
- Gerenciamento de contas
- Controle de cartões
- Acompanhamento manual de investimentos
- Visualização de dados financeiros

## Tecnologias

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Java
- Spring Boot

### Banco de dados
- SQL
- PostgreSQL

## Desenvolvimento

O projeto está sendo desenvolvido de forma incremental, passando por etapas
de frontend, lógica com JavaScript, persistência local, backend, banco de dados
e integração entre as partes.
